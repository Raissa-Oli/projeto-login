# 🔐 Tela de Login

Projeto de uma **tela de login responsiva**, desenvolvido durante os estudos de **HTML5 e CSS3**.

A proposta foi criar uma interface de login organizada e adaptável a diferentes tamanhos de tela, utilizando recursos de HTML, CSS, Media Queries e ícones do Material Icons.

## 🌐 Projeto online

Acesse o projeto publicado pelo GitHub Pages:

🔗 **[Visualizar Tela de Login](https://raissa-oli.github.io/projeto-login/)**

## 📸 Sobre o projeto

A aplicação apresenta uma tela de login com:

* Campo para e-mail;
* Campo para senha;
* Botão de entrada;
* Opção para recuperação de senha;
* Ícones para identificação dos campos;
* Imagem integrada ao layout;
* Design adaptável para diferentes dispositivos.

O projeto foi desenvolvido com foco na prática de **estruturação de formulários, estilização com CSS e criação de layouts responsivos**.

## 🎨 Funcionalidades

### 🔑 Formulário de Login

O formulário possui campos para:

* E-mail;
* Senha;
* Botão "Entrar";
* Link "Esqueci a senha".

Os campos também possuem algumas validações utilizando atributos HTML, como:

* `required`
* `maxlength`
* `minlength`
* `autocomplete`

### 📱 Design Responsivo

O projeto utiliza **Media Queries** para adaptar a interface a diferentes tamanhos de tela, proporcionando uma melhor experiência em:

* 💻 Computadores
* 📱 Celulares
* 📲 Tablets

### 🎯 Material Icons

Foram utilizados ícones da biblioteca **Material Icons** para representar visualmente os campos de usuário, senha e recuperação de senha.
